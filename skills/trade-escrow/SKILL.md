# Trade Escrow — 交易保障托管

## 触发条件

用户表达以下意图时加载此技能：
- "付款后卖家不发货怎么办"
- "怎么保证交易安全"
- "帮我做托管交易"
- "货到付款怎么操作"

## 执行流程

### 1. 确认交易参数

- **买方**：用户（收货方）
- **卖方**：供应商
- **交易金额**：商品总价
- **商品**：具体描述/规格/数量
- **托管条件**：买方收到货并验货后放款

### 2. 解释托管流程

```
🛡 交易保障托管流程

买方                托管方              卖方
 │                    │                  │
 ├─①付款到托管────────→│                  │
 │                    │──②通知卖方发货───→│
 │                    │                  │──③发货
 │←──────────────────④收货验货───────────┤
 │                    │                  │
 │──⑤确认收货─────────→│                  │
 │                    │──⑥放款给卖方─────→│
 │←─收到商品──────────┤←─收到货款─────────┤
```

### 3. 生成托管凭证

```
🛡 交易托管凭证

交易编号：ESCROW-<日期>-<序号>
买方：<买方名>
卖方：<卖方名>
交易金额：¥XX
商品：<商品名> × <数量>

托管条件：
  ✅ 买方收货后 X 天内验货
  ✅ 验货通过 → 放款给卖方
  ✅ 验货不通过 → 退回货物 → 退款给买方
  ✅ 超时未确认 → 自动放款（X天）

争议处理：
  ⚖ 双方对商品质量有争议时，由托管方协调
  ⚖ 提供物流签收记录和商品照片作为证据
```

### 4. 跟踪托管状态

```
📌 托管状态

| 状态 | 说明 |
|:--:|------|
| 💰 已付款 | 买方已付款到托管，等待卖方发货 |
| 📦 已发货 | 卖方已发货，等待买方收货 |
| ✅ 已完成 | 买方确认收货，货款已放款 |
| 🔄 退货中 | 验货不通过，正在退货退款 |
| ⚖ 争议中 | 双方有争议，等待协调处理 |
```

### 5. 完成托管

- 买方收到货 → 验货 → 确认放款
- 如果超时不确认 → 系统自动放款（保护卖方）
- 如果验货不通过 → 发起退货 → 退款给买方（保护买方）

## 注意事项

- **验货期**：收到货后 X 天内验货（建议 3-7 天），超时自动放款
- **证据保留**：开箱时拍照/录像，物流面单保留
- **争议处理**：双方友好协商优先，协商不成由第三方协调
- **大额交易**：建议分批次托管，降低单次风险
